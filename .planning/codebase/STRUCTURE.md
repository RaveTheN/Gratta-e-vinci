## Directory Purposes

**Root directory (flat layout):**
- Purpose: All source code lives at the project root; there are no subdirectories for source code
- Contains: Python modules, config files, batch scripts, legacy JS files (tracked but deleted on current branch)
- Key files: `gratta_e_vinci_gui.py`, `game_engine.py`, `game_config.py`

**`.planning/codebase/`:**
- Purpose: Codebase analysis documents generated by GSD mapping
- Contains: Markdown analysis files (ARCHITECTURE.md, STRUCTURE.md, etc.)
- Generated: Yes
- Committed: Yes

## Key File Locations

**Entry Points:**
- `gratta_e_vinci_gui.py`: Main application entry point; contains `if __name__ == "__main__"` block
- `run_gui.bat`: Windows launcher that invokes `gratta_e_vinci_gui.py` via `.venv` Python
- `setup.bat`: First-time setup script (creates venv, installs dependencies)
- `mouseMonitoring.py`: Standalone utility for printing mouse coordinates

**Configuration:**
- `gratta_settings.json`: Runtime settings (coordinates, betting modes, pauses); auto-loaded on startup, manually saved
- `requirements.txt`: Python package dependencies
- `game_config.py`: Compile-time constants (betting modes, colors, multipliers, board size)

**Core Logic:**
- `game_engine.py`: `GameEngine` class (game loop, strategy, test simulation) and `TkAutomationAdapter` (physical I/O)
- `color_detector.py`: `ColorDetector` class (pixel reading and blue/red classification)
- `coordinate_manager.py`: `CoordinateManager` (grid math) and `CoordinateRecorder` (interactive overlay)
- `settings_manager.py`: `SettingsManager` class (JSON load/save with defaults and validation)

**Testing:**
- No test files exist. Test mode is an in-app simulation feature, not automated tests.

**Legacy (inactive):**
- `package.json`, `package-lock.json`: Node.js dependencies for the original JavaScript version (nut-js, tesseract.js). Not used by the Python application. Deleted files on current branch: `autoplay.js`, `playM.js`.

## Naming Conventions

**Files:**
- Python modules: `snake_case.py` (e.g., `game_engine.py`, `color_detector.py`, `settings_manager.py`)
- Exception: `mouseMonitoring.py` uses camelCase (legacy)
- Exception: `gratta_e_vinci_gui.py` uses project name with underscores
- Batch scripts: `snake_case.bat` (e.g., `run_gui.bat`, `setup.bat`)

**Classes:**
- PascalCase: `GrattaEVinciGUI`, `GameEngine`, `TkAutomationAdapter`, `ColorDetector`, `CoordinateManager`, `CoordinateRecorder`, `SettingsManager`, `Point`

**Methods:**
- `snake_case` for public methods: `start_game()`, `stop_game()`, `load_settings()`
- Leading underscore for private/internal: `_get_round_config_for_strategy()`, `_apply_test_win()`, `_on_mode_changed_settings()`
- GUI widget creation: `create_*_tab()` pattern (e.g., `create_settings_tab()`, `create_control_tab()`)

**Variables:**
- Tkinter variables: `snake_case_var` suffix (e.g., `starting_cash_var`, `mode_var`, `sleep_after_play_var`)
- Game state: plain `snake_case` (e.g., `current_cash`, `highest_bet`, `grinding_active`)

## Where to Add New Code

**New Game Feature (strategy, betting logic):**
- Primary code: `game_engine.py` (add methods to `GameEngine` class)
- Constants: `game_config.py` (add new constants, types, or config values)
- GUI integration: `gratta_e_vinci_gui.py` (add widgets and connect to engine)

**New Automation Action (mouse/screen interaction):**
- Implementation: `game_engine.py` (add method to `TkAutomationAdapter` class)
- Color-related: `color_detector.py` (extend `ColorDetector`)

**New GUI Tab:**
- Implementation: `gratta_e_vinci_gui.py` (add `create_*_tab()` method, register in `create_widgets()`)
- Pattern: Follow existing tab creation pattern in `create_settings_tab()`, `create_control_tab()`, etc.

**New Settings Field:**
- Add default value in `settings_manager.py` `_build_defaults()`
- Add validation in `settings_manager.py` `validate()`
- Add `tk.*Var` in `GrattaEVinciGUI.__init__()`
- Add widget in appropriate `create_*_tab()` method
- Update `on_save_settings()` and `on_load_settings()` in the GUI class

**New Coordinate Feature:**
- Grid logic: `coordinate_manager.py` (extend `CoordinateManager`)
- Recording: `coordinate_manager.py` (extend `CoordinateRecorder`)

**New Utility Module:**
- Place at project root as `module_name.py` (flat structure)
- Import in consuming modules; add shared constants to `game_config.py`

## Module Dependency Graph

```
game_config.py          (leaf - no dependencies)
    ^
    |
    +-- color_detector.py
    +-- coordinate_manager.py
    +-- settings_manager.py
    +-- game_engine.py -----> color_detector.py (via TkAutomationAdapter)
    +-- gratta_e_vinci_gui.py --> game_engine.py
                              --> color_detector.py
```

All modules except `game_config.py` and `mouseMonitoring.py` depend on `game_config.py`. The GUI module (`gratta_e_vinci_gui.py`) imports all other modules and serves as the composition root.
